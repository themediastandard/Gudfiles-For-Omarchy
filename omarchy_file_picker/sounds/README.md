# Gudfiles action sounds

Four original synthesized cues: a soft drop, paper-like Trash rustle, lower
permanent-delete tap and a short completion chime. No recordings or external
samples are used. Regenerate them with `python scripts/generate_sounds.py` from
the repository root. They are mono 24 kHz, 16-bit PCM WAVs lasting 170–320 ms.

The app plays at half stream volume under the separate **Gudfiles Sound Effects**
audio identity. Media preview volume and system output settings are unaffected.
