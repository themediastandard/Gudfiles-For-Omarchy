# Gudfiles 0.1.1

- Fix thumbnail decoder aborts caused by insufficient virtual address space for
  Glycin's image-loading threads. Isolated decoders retain memory, CPU, output
  size and wall-clock limits.
- Log bounded decoder error details instead of silently discarding them. Failed
  thumbnails continue to show the ordinary file icon.
- Decode source images once while collecting dimensions, avoiding a second full
  decode for metadata. Refill thumbnail workers immediately, load in display
  order, and prioritize selected-file previews in the browser and Open/Save dialogs.
- Simplify popup footers to their essential actions and save filename; remove the
  popup preview strip while retaining the caller's file filters and custom options.
- Show real image, RAW and video thumbnails in compact list rows.
- Drag the right edge of the Name heading to resize filenames, or double-click
  it to fit the longest filename in the current list. The width is remembered.
