# Gudfiles 0.1.0

The first public release of Gudfiles, designed and built by The Media Standard
for creatives using Linux. Free for personal and commercial use under the
included Gudfiles Free Use License; modification and redistribution rights are
reserved.

- Browse in grid, list and column views with folder tabs.
- Preview images, video, text and PDFs; organize selects with ratings and colors.
- Copy and move files with progress, pause, cancellation and transfer queues.
- Use native Open/Save dialogs, familiar shortcuts and searchable Help.
- Follow the active Omarchy theme, with polished light and dark appearances.
- Check the current version and public releases in Help → About & License.

Targets current Omarchy on Arch Linux. Extra codecs, media tools and network
backends enable the corresponding optional features. Camera RAW previews need
the separately installed `raw-preview` helper; that helper is not bundled.

Finish transfers and close Gudfiles before installing or updating. Reopen it
afterward. Preferences, ratings and bookmarks remain in their existing locations.
See the included installation guide for portal setup and package updates.
