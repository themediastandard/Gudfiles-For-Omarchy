# Gudfiles 0.1.2

- Add persistent Favorites and Recents sections to the browser and file pickers.
  Right-click folders to favorite them; Recents remembers the five most recently
  used folders, including folders used for file choices and file actions.
- Remove individual Favorites or Recents shortcuts without deleting files or
  folders. Preserve existing bookmarks and the separate Recent Files view.
- Keep startup, background refreshes and recovered transfer receipts from
  adding folders to Recents.
- Use smaller, aligned uppercase empty-state labels and highlight only one
  sidebar shortcut for the current folder.
- Show the large bottom preview only for selected photos, camera RAW images or
  videos. Return that space to the file list for other selections, while keeping
  the compact file-count and size bar visible.

## Update discovery

Ordinary browser launches now check for newer stable Gudfiles packages in the
background and show a small dismissible download notice. Open/Save dialogs stay
quiet. Help retains a manual check. Downloads and installation remain explicit;
old preview users must install this version once to gain future launch notices.
